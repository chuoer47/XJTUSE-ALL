# Python综合训练

XJTUSE Python 综合训练的部分代码和完整实验报告。

以西安二手房数据为主线，串起爬取 → 清洗 → 建模 → 可视化四个 demo。

## 目录结构

- `demo1_数据爬取/` —— 爬取西安二手房数据（`demo1.py` + 报告 docx + csv）
- `demo2_办公自动化/` —— 数据清洗与办公自动化（`demo2_1/2/3.py` + 词云 + xlsx）
- `demo3_模型的建立/` —— 建立回归/AdaBoost 模型（`ada模型.py` / `最小二乘模拟.py` + 预测图/特征重要性图）
- `demo4_可视化/` —— 数据可视化（`demo1.py` + `实验四可视化相关code.py` + 神经网络示意图）
- `Python实验报告.pdf` —— 完整实验报告
