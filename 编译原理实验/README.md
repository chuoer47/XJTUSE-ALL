# 编译原理实验

编译原理课程的实验代码，基于 Python 实现，涵盖词法分析、语法/语义分析等。

## 目录结构

- `config.py` —— 公共配置
- `fileSet/` —— lab1/lab2 的输入输出测试数据
- `lab1/` —— 实验1
- `lab2/` —— 实验2
- `lab3/` —— 实验3（词法分析 `lexer.py`、语义分析 `sema.py`、文法 `productions.txt`、`util.py`、`dataset/` 测试数据）
