# 面向对象综合训练

面向对象程序设计综合训练，使用 Java 实现扫雷游戏。

## 目录结构

- `minesweeper/` —— 扫雷基础版（`Cell` / `GameBoardPanel` / `MineMap` / `MineSweeperMain`）
- `myMinesweeper/` —— 扫雷完整版（含菜单 `Menu`、计时 `MyTimer`、难度选择 `Select`、工具 `Tool`、`Play` 等）
- `img/` —— 游戏素材（表情、旗帜、地雷图标）
- `面向对象程序设计综合训练-Minesweeper.pdf` —— 实验报告
